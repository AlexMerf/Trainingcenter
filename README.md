# Trainingcenter

Архив проекта сайта учебного центра «Специалист» (2023) и его современная перезапущенная версия.

## Структура репозитория

- **`site/`** — новый сайт: Astro 5 + TypeScript + Tailwind CSS 4.
  Быстрый старт и описание — в [`site/README.md`](site/README.md).
- **корень репозитория** — архивная версия 2023 года, сохранённая без изменений:
  - `index.html`, `directions.html`, `jobs-page.html`, `contacts-page.html`,
    `info-organization.html`, `politic.html`, `404.html` — собранные страницы;
  - `pages/` — HTML-исходники с include-директивами (`<!--=include ...-->`);
  - `components/` — 18 переиспользуемых блоков;
  - `css/style.min.css`, `js/main.min.js` — минифицированные бандлы;
  - `images/` — изображения и SVG-иконки.

## Современная версия

Смотреть новую версию: [`site/`](site/).

```bash
cd site
pnpm install
pnpm dev
```

Скриншоты страниц новой версии — в [`shots/`](shots/).

## История

Архивный сайт собран в июне 2023 года на Gulp-шаблоне (страницы + include-компоненты),
без сохранённого сборщика в репозитории. Перезапуск 2026 года переносит контент и идеи
в современный стек, сохраняя архив в исходном виде.

## Статус

Портфолио-демо. Формы демонстрационные (отправка не подключена), реквизиты, цены и документы —
примеры. Использовать как основу реального сайта можно после подключения бэкенда форм,
реальных документов и контента.

Направления

Охрана труда

Программа обучения по охране труда для руководителей и специалистов организации

Пожарная безопасность

Пожарно-технический минимум для руководителей подразделений пожароопасных производств

Электробезопасность

Программа обучения по электробезопасности предназначена для специалистов, работающих с электроустановками

Первая помощь

Курс по первой помощи предназначен для обучения людей основам оказания медицинской помощи при несчастных случаях и экстренных ситуациях

Экология

Программа обучения по экологии направлена на расширение понимания важности экологической устойчивости и развития навыков по оценке и управлению окружающей средой

Промышленная безопасность

Программа обучения по промышленной безопасности предназначена для руководителей и специалистов, работающих на промышленных предприятиях

Обучение профессиям

Программа обучения профессиям предоставляет возможность специалистам приобрести или усовершенствовать навыки в определенной профессиональной области
